# Fonte

Alle fonte i dette tema skal kunne videredistribueres under en licens der er
forenelig med GPL-2.0, fordi repoet er offentligt og temaet indlejrer filerne
og serverer dem til besoegende.

Myriad Pro (Adobe) og Impact (Monotype) er desktop-licenser og maa **ikke**
ligge her. De er byttet til deres frie slaegtninge.

## Filer der skal ligge i denne mappe

| Fil | Familie | Kilde |
|---|---|---|
| `SourceSans3-Variable.woff2` | Source Sans 3, 300-700 normal | github.com/adobe-fonts/source-sans |
| `SourceSans3-Italic-Variable.woff2` | Source Sans 3, 300-700 kursiv | samme |
| `SourceSerif4-Variable.woff2` | Source Serif 4, 300-700 normal | github.com/adobe-fonts/source-serif |
| `SourceSerif4-Italic-Variable.woff2` | Source Serif 4, 300-600 kursiv | samme |
| `Anton-Regular.woff2` | Anton, 400 | github.com/google/fonts (ofl/anton) |

Filnavnene er de navne `theme.json` peger paa. Hedder en fil noget andet,
indlaeses den ikke.

## Licenser

SIL Open Font License 1.1 kraever at licensteksten foelger filerne. Laeg dem
ved som:

- `LICENSE-source-sans-3.txt`
- `LICENSE-source-serif-4.txt`
- `LICENSE-anton.txt`

Hentes fra hver fonts eget repo (`OFL.txt`).
